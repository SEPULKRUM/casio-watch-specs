# Worldwide registers, 2020–2026

The eleven supplied JSON registers contain 931 observations for 924 exact identifiers: 865 individual watch references, 54 partial family or announcement codes, and five paired-watch packages. Seven exact references occur in both seed and expanded files. All observations, source URLs, release-status qualifications, prices, interpretations and unresolved questions are retained under `worldwide_evidence`. This is a partial research inventory, not a claim of worldwide completeness.

Run `python worldwide_import.py` then `python catalog.py build`. Both commands support `--check`. The generated technical addendum composes with the public base without replacing its existing bulk artifacts. The beta uses the rebuilt catalog and index.

Individual IDs retain their full color and market endings. Existing regional presentation rules may group documented equivalent retail references, preserving exact-reference access. Partial codes and paired sets remain accessible outside individual-watch counts. No normalized base-reference field creates an extra watch.

Source assertions of manufacturer confirmation remain supplied claims pending independent archived-source review. Existing catalog fields are preserved, including equal-valued facts and their provenance. Conflicting new values remain visible in the per-model evidence rather than replacing existing facts. Physical measurements are never copied from module profiles or sibling variants. Newly associated modules without researched functions receive an association-only pending profile. No Shockbase sources are used.

Tests reconcile every supplied identifier, search every model, execute all register detail-rendering paths, and verify reproducible generated artifacts. Original uploads are not offered as downloads.

Regional market endings identify stored references for the same complete color/design code. Source-description or recorded-specification disagreements remain inside the reference group rather than generating duplicate watch rows. Every exact observation and detail link remains accessible. Availability labels describe whether specifications exist; independent source-check status remains separate and is never inferred from availability.
