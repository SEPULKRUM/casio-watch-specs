# 2011 watch-family and clock index import

The owner supplied a 16-page text extraction, **Casio_2011_Catalog_Model_Specifications.pdf**, derived from a 144-page Japanese 2011 dealer catalog. Preserve all **311 watch index rows** and **109 clock rows**. The watch table describes base/family labels rather than every pictured colour, band or regional SKU. Original scanned pages have not been independently rechecked; incoming facts are supplied secondary evidence pending review.

## Counts and scope

The 311 watch rows contain 310 unique base identifiers: SDB-100J appears twice for two explicitly labelled suffix/weight groups. Together with 109 unique clocks, this adds **419 indexed reference records**, not 420 new retail variants. None of these identifiers previously had a catalog record; earlier source observations may already exist in the research library.

Sixteen printed watch groups are retained in the source panel. These headings remain extraction grouping, not independently validated manufacturer classification. For example, the broad G-SHOCK group includes AW-80; this import does not assert every listed entry is a G-SHOCK. New records use **2011 Watch Index** or **2011 Clock Index** and carry explicit `reference_scope` metadata.

## Preserved values and unknowns

- Indexed dimensions and mass use dedicated `indexed_dimensions_mm` / `indexed_weight_g` fields. They are not exact-retail-variant `dimensions_mm` / `weight_g` assertions. Material, colour, water resistance, functions and release dates are not guessed.
- SDB-100J (1AJF/1BJF) retains 28.2 g; SDB-100J (3AJF/4AJF) retains 27.5 g. Both labels/values remain in its source rows and scoped measurement claims. No single mass is selected and no four complete retail SKUs are reconstructed.
- Module values are retained only where legible in the supplied index. Four rows preserve alternatives: LQ-139AMV, LQ-398GL and LQ-410 list 705 / 1330; MW-59 lists 708 / 2784. These are index-level associations, not fitted-module determinations for every individual watch.
- 227 printed watch rows have no established module, representing 226 distinct base labels. These fields remain blank. All 109 clocks have no guessed technical measurements or modules.
- 48 distinct module numbers receive index-association notes, adding 38 previously absent identities. No module functions are created from this source. Existing profiles retain their earlier facts; the interface distinguishes index associations from fitted-module verification.
- The catalog year is not a release date. Dashes mean not reliably established by the extraction, not zero or proof of absence.

## Pagination

Both source levels are retained:

1. Page within the supplied 16-page extraction.
2. Original watch-size table: physical PDF page **142**, printed page **140**.
3. Original model/module index: physical PDF page **143**, printed page **141**.
4. Printed product page(s) associated with each row, when established. Original physical product PDF page = printed page + 2. Ranges and slash-separated page references are preserved as page lists.

No original scans, advertisements, catalog artwork or photographs are distributed.

## Files and access

`catalog_2011_import.py` parses the supplied PDF's watch tables and two-column clock index. `research/catalog-index-2011-2026-11-15.json` contains selected facts, source checksum, original labels, locators, limits and checksum-bound evidence claims. The identifier supplement records watch labels as family references and clocks as clock-index references. `web/catalog-2011-reference.mjs` powers the full grouped source panel. CSV includes indexed measurements, record scope and the complete scoped 2011 reference.

Totals after import: **1,017 catalog references** (904 watch/model/family references and 113 clocks), **251 module identities/profiles**, **7,093 candidate fields**, **3,116 research model strings** and **209 family/prefix references**.
