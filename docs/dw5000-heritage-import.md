# DW-5000 heritage PDF implementation

The 14-page supplied reference contains 22 canonical heritage records: 20 conventional watch identifiers and two Honda collector descriptions. These are distinct from the related DW-1983-1 homage, four preserved legacy case-family records and GSET-30-1 package. All 28 reference strings remain accessible with explicit categories. Honda labels are not converted to concatenated synthetic SKUs. The 1993 DW-1983 reference remains outside the canonical 22.

`research/supplied-dw5000-heritage-2026-11-17.json` records the PDF hash, page locators, supplied source hyperlinks, archive lookup results, complete structured decoder explanations and scope limits. Rebuild with `python dw_heritage_import.py`; verify with `--check`. Photographs and original/reconstructed catalog artwork are not distributed. Page 3 measurement photographs were visually inspected; the displayed caliper and scale readings agree with the table. Archive CDX metadata is not independent snapshot-content verification, so claims remain pending.

DW-5000C and DW-5200C observations are 46.8 × 41.3 × 12.8 mm with 64.65 / 64.70 g complete weights including original Casio 18 mm bands. These describe individual specimens without asserted color suffixes. No vintage variant receives these as factory dimension/weight scalars. The separate historical 41.6 mm width is retained with its possible convention difference. DW-5400C and DW-5500C remain unmeasured. Published modern figures are assigned only to the four specific modern references named in the source; DW-5000R is a December 2024 regular-production revival.

Module 240's period functions remain separate from physical watch specifications. Other module entries preserve reported model associations and explicitly stated illumination only, without inventing full function tables. Existing specifications and citations remain unchanged. DW-5000C-1B / DW-5035D-1B decoder B describes the supplied black/gold design rather than the generic blackout guess; C, SP, PG, RX and other literal expansions remain scoped and unverified.

Recorded service-part codes retain their exact strings, including replacement stock 09521081. Replacement compatibility is not original fitment. The rejected gold-crystal assignment 79000433 is never listed as a positive part association; the original DW-5000C-1B crystal remains unresolved. Module-based creator playlists and regional-reference grouping remain intact.
